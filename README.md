# Invoice App

An invoice and vendor management app built with React + Vite + Supabase + shadcn/ui.

## Setup

1. Clone the repo
2. Run `npm install`
3. Copy `.env.example` to `.env.local` and fill in your Supabase credentials
4. Run `npm run dev`

## Supabase Setup

Create a free project at [supabase.com](https://supabase.com) and run the SQL from `supabase/schema.sql`.

## Stack
- React 18 + Vite
- Supabase (Auth + Database)
- Tailwind CSS + shadcn/ui
- React Router v6
- Recharts
